# TastyBite Project Guidelines

## Image Assets
- **Strict Location**: ALL images used across the TastyBite website (current or future) MUST be stored inside `frontend/public/pictures-restaurant/`.
- **Paths**: In React components and CSS stylesheets, reference images using `/pictures-restaurant/<filename>.webp`.
- **No External CDNs**: Do not use external image URLs (e.g. Unsplash, external links). All assets must be local in `public/pictures-restaurant/`.
