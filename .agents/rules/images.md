# Image Assets Directory Rule
All static images, dish photos, restaurant ambiance pictures, hero banners, logos, and UI assets (present or future) must be placed inside the `public/pictures-restaurant/` directory (e.g. `frontend/public/pictures-restaurant/`).

## Guidelines:
1. **Directory Location**: `frontend/public/pictures-restaurant/<filename>.webp`
2. **Referencing in Code**: Reference images via absolute web path `/pictures-restaurant/<filename>.webp`
3. **No External URLs**: Never use external image hosting links (e.g., Unsplash, Imgur, or external CDNs) for static website images. All image assets must reside in `public/pictures-restaurant/`.
4. **Format**: Prefer optimized `.webp` format for fast loading and crisp visuals.
